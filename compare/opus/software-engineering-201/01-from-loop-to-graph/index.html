From Loop to Graph Coming soon

The idea

A loop makes one unit of work correct. A graph decides which units exist, and which of them can run at the same time.

Draft outline. Titles and ideas may change before the lesson is made.

The premise of 201

101 was about one piece of work: getting one fix or one feature right. That's the loop. 201 is the layer above: how work is split, what runs in parallel, where a person decides, and how each run makes the next one better. That's the graph.
