Copy this for yourself

This site is a demonstration of how an OpenBook and a short video learning series can be built in the open, with AI, the way a software project is run. You are welcome to copy the idea and the repository for your own work.

Use it as a template

The repository is a GitHub template. On clarkhuang/clarkhuang.github.io, choose Use this template, then Create a new repository. Or fork the repository if you would rather keep a link to the original.

  1. Create your copy of the repository.
  2. In the repository settings, turn on GitHub Pages from the main branch, at the root.
  3. Replace the home-page bio, the lesson text, and the book preview with your own material. Keep the llms.txt, AGENTS.md, and “Use this page with your AI” prompt, so other people (and their AIs) can read your site the same way.
  4. If you keep the OpenBook workflow, leave the issue templates, the approved label gate, and the next-revision branch in place, then add your own review rules.

The live site is static: plain HTML, CSS, and a small script, plus video and audio files. There is no build step on GitHub Pages. The generator that produces the pages lives alongside the published files in this project, so you can change the source and regenerate, or edit the HTML directly.

What you can and cannot copy
