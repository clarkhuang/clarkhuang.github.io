# Contributing to the OpenBook

The project-wide guide is at [../CONTRIBUTING.md](../CONTRIBUTING.md). This file is the book-specific pointer.

- File a [correction](https://github.com/clarkhuang/clarkhuang.github.io/issues/new?template=correction.yml) to edit existing book text, or to tell your side of a story.
- File a [new story](https://github.com/clarkhuang/clarkhuang.github.io/issues/new?template=new-story.yml) for a story that is not in the book yet.
- File a [refactor](https://github.com/clarkhuang/clarkhuang.github.io/issues/new?template=refactor.yml) for cleanup that does not change the facts.
- Pull requests for book changes target the `next-revision` branch.
- Only Clark approves, triggers agents, merges, and cuts a new edition.

See [VERSIONING.md](VERSIONING.md) and [README.md](README.md).
