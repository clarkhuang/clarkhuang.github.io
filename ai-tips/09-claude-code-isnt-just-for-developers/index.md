## The lesson

Claude Code's name keeps most non-developers away, but it works on any folder of ordinary files, driven by plain-English requests. This tip shows what it can do with screenshots, invoices and transcripts, what "it's a terminal" really means, and how to start in five minutes.

## The rule

For any job that means reading, renaming, or pulling information across many files in one folder, try Claude Code before doing it by hand: install it, point it at the folder, and describe the outcome in plain English. Use Esc to interrupt, /help to see what it can do, and the desktop app if you'd rather not use a terminal. Check the result before relying on it.

This rule is written so an AI agent can follow it as a standing instruction.

## Transcript

There's a tool most people will never open, purely because of its name.

### The name

It's called Claude Code. So if you don't write software, you've read that name and quietly decided it isn't for you. That one word is costing you a lot of time.

Anthropic's own guide for first-time terminal users says it in one line. You don't need to know how to code. Describe what you want, in plain English.

### What it is

Here's what it actually is. You point it at a folder on your computer. Any folder. Not a codebase: a folder of documents. Then you talk to it about what's in there.

### What it does

This one's straight from the documentation. Look at the screenshots on my Desktop, and rename them based on what's in each image. It opens each one, works out what it shows, and renames the lot.

Now one I'd actually use. A folder of vendor invoices: PDFs, a few scans, a spreadsheet somebody started and abandoned. Ask for one table of what's in them, and it reads across every file and builds it.

It isn't magic. It reads your files, and where it needs to, it writes and runs a little code to do the work. You never see that part unless you want to.

Same move, different shape. Hundreds of meeting transcripts. Find every time we discussed a decision, and tell me what was agreed. It doesn't search them. It reads them. All of them.

### Why this one

And it works on your machine, on the folder itself. You don't upload files and download results. It reads and edits them right where they already are.

### The trade

Now the honest part. It's a terminal: you type instead of click. In practice, that means arrow keys, not the mouse. Escape stops it if it heads the wrong way. Slash help shows what it can do. Everything else is plain English.

And if that's still a no, skip the terminal entirely. There's a desktop app. Same tool, a window instead of a prompt.

### Getting started

Want to try it? Three steps, about five minutes. Install it with one line, pasted into a terminal. Point it at a folder you already have. Then describe what you want.

The name really is the hardest part. Behind it, it's a folder of your own files, and a sentence about what you want done to them.

Point it at a folder. See what happens.
