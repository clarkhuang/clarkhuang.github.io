Stop Re-Explaining Yourself

2:18·Narrated in Clark's AI voice·Download MP4Not watched✓Watched

Up next: Lesson 9: Claude Code Isn't Just for Developers

The lesson

If every Claude chat starts with you re-explaining your job and re-attaching the same file, a Project fixes it: shared knowledge and instructions in one place. This tip covers what sharing a project hands over (and what stays private), the permission choices, and where Cowork tasks run.

The rule · for your agents

When you find yourself re-uploading the same files or repeating the same instructions, put them in a Claude Project: files in project knowledge, standing rules in project instructions. Share the project with the people who'd benefit. Sharing hands over knowledge and instructions, while each person's chats stay private unless they share one deliberately. Choose org-wide or invite-only, and can-view or can-edit. If a task "can't see" your local folder, check whether it needs the desktop app open.
