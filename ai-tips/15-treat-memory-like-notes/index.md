## The lesson

AI memory is a small set of saved notes, not a mind. Notes can be never saved, saved wrong, off-topic or stale, and they won't keep up unless you update them.

## The rule

Treat memory like notes: say what matters in the prompt, don't assume a new chat knows, read your memory now and then, and fix or delete what's wrong.

This rule is written so an AI agent can follow it as a standing instruction.

## Transcript

We picture A.I. memory as a mind that knows us. It's closer to a notebook. And a notebook is only as good as its last edit.

### The problem

Months ago, you mentioned a side project was on hold, and the tool saved a note. Side project: on hold.

Last week, you restarted it. Now you ask a new chat for a weekly plan. And it plans around a project that's on hold.

### Why it happens

Here's what memory actually is. A new chat starts mostly blank. Memory is a small set of saved notes the tool sometimes pulls in, or searches. Tools differ, and none of them keep everything. And a note stays exactly as written, until somebody changes it.

### Where it shows up

So it goes wrong in four predictable ways. Never saved: something you assumed it knew. Saved wrong. Off-topic: an old detail where it doesn't belong. Or stale: true once, not now. And every one has a simple fix.

### The tell

The tell is advice that doesn't fit your life right now, or an old detail that turns up out of nowhere. When you see it, don't just argue with the chat. Go read the note. Fix it, or add it.

### The habit

So change the picture. Not a mind that keeps up with you. A notebook you own, that won't keep up unless you update it.

Here's the rule. When a fact matters, say it in the prompt. Don't assume a new chat knows. Read your memory now and then. And fix or delete what's wrong.

Your turn. Open your memory settings today and read what's saved about you. Reply with the note that surprised you most.

It's not a mind. It's a notebook. Keep it current.
