Define the Number Before You Ask for It

2:06·Narrated in Clark's AI voice·Download MP4Not watched✓Watched

Up next: Lesson 4: Know What the Bot Can Actually Reach

The lesson

Ask a bot for a number with a loose word in it and it will quietly pick a meaning, then hand you a confident, wrong answer. This tip shows how one word like "got" or "orders" can mean several populations, and the one extra sentence that removes the guess.

The rule · for your agents

Before asking any agent or analyst for a number, state three things: the exact metric (which event, which status), the source system your team signs off on, and the as-of date. Where you can, add a number you already know ("this should land near X, tell me if it doesn't") so the answer has to reconcile. If a vague question gets a fast, confident answer, treat that speed as the warning sign and ask what interpretation was used.
