# SE 401 Video 1 — Build the Baseline

[Watch the captioned lesson](https://clarkhuang.github.io/software-engineering-401/01-build-the-baseline/)

## The rule

Write a handoff you would trust, score it against the source notes, then apply the same checks to a model’s draft.

## Transcript

Imagine the evening coordinator has thirty seconds to tell tomorrow's crew what changed. Before choosing an AI model, write one handoff you would trust.

Read these three lines. Jo owns the crate pickup. The key has a location. The driver is still unconfirmed. Pause here and write the handoff you would give the morning crew.

Here is one reference answer. It keeps the owner and deadline, points back to the source lines, and leaves the open question open. Save your version before looking at a model draft.

Decide now what earns a pass. Could someone act on the deadline? Can you trace every statement? Would an unknown assignment still look unknown? These checks work with any model.

Score this deliberately flawed draft. It sounds efficient: Jo drives Route B at nine. But that sentence joined two unrelated facts. Someone reading it might stop looking for a driver.

Mark the exact claim that failed. Keep the original notes, reference answer, rubric, draft and decision together. When you run a real model, add its version, elapsed time and the edits the coordinator made.

Try the exercise with a second set of fictional notes the model has never seen. Score its answer before you change the prompt. That gives you something to compare when the local Studio is ready.
