Contribute with your AI

You do not have to be a programmer. Point any AI chat tool at this site, tell it what you know, and let it draft a GitHub issue. Clark reviews every issue and is the only person who can approve work or publish it.

If your contribution lands on the site, you will be credited on the Contributors page in the same pull request, unless you ask not to be. Credits use your public GitHub display name when your profile has one, otherwise your handle, or the name you consented to publish on a guest story. First-person guest stories, once accepted, appear at Guest stories.

The prompt

Copy this, paste it into ChatGPT, Claude, Grok, or any other chat tool, then add your story or idea in your own words.

Please help me contribute to Clark Huang's free OpenBook and learning site at https://clarkhuang.github.io/

1. Read https://clarkhuang.github.io/llms.txt and https://clarkhuang.github.io/AGENTS.md (and the AGENTS.md next to any page I share with you).
2. Look at open issues: https://github.com/clarkhuang/clarkhuang.github.io/issues
3. Either pick an open issue labeled "good first issue", or help me propose one of these:
   - a correction (an edit to the book, or my side of a story already in it)
   - a new story or chapter idea
   - a refactor (cleanup or an improvement that does not change the facts)
4. Draft a GitHub issue I can paste, using the matching template:
   - Correction: https://github.com/clarkhuang/clarkhuang.github.io/issues/new?template=correction.yml
   - New story: https://github.com/clarkhuang/clarkhuang.github.io/issues/new?template=new-story.yml
   - Refactor: https://github.com/clarkhuang/clarkhuang.github.io/issues/new?template=refactor.yml
5. Do not invent stories or details. Do not use real names of private people, or real company names, in story submissions. Describe people by role and companies in general terms. Stick to what I actually tell you.

If you would rather skip GitHub

You still use a short GitHub form — that is how proposals are tracked, like in an open-source project. You do not need to write code. Open the share-a-story form (or the correction or refactor form), and ask your AI to help you fill it in. You can paste the prompt above first, then the form fields.

Please do not include real names of private people, or real company names, in a story. Describe people by role (“my lab partner,” “a team lead”) and companies in general terms (“a startup in San Francisco,” “a firm from Berlin”).

What happens next

  1. Your issue is labeled for Clark to review.
  2. If he wants it built, he adds an approved label. Only his label or comment starts an agent.
  3. An agent drafts the change as a pull request. Nothing goes live until Clark merges it.

Connect your AI (MCP)

First-party option: this site also ships its own small, read-only site MCP server (stdio, one Python file, no dependencies) with tools for lessons, transcripts, captions, media checks, search, and contributor-style issue drafts. Claude Code: claude mcp add clarkhuang-site -- uv run https://clarkhuang.github.io/mcp/clarkhuang_site_mcp.py. The GitMCP endpoint below is a remote, third-party alternative; its full-text fetch is current, but its search can lag behind the site.

This project has a public, read-only GitMCP endpoint:

https://gitmcp.io/clarkhuang/clarkhuang.github.io

GitMCP is a free third-party service. It is not affiliated with this site. It only reads public documentation (it prefers llms.txt) and public code. It cannot open issues, merge pull requests, or change the book. Contributions still go through GitHub issues, as described above.

The tools it exposes for this repository are fetch_clarkhuang_docs, search_clarkhuang_docs, search_clarkhuang_code, and fetch_generic_url_content.

Claude Code

claude mcp add --transport http clarkhuang https://gitmcp.io/clarkhuang/clarkhuang.github.io

Claude Desktop

If your Claude Desktop build supports a remote HTTP MCP server, add the URL above. Otherwise use the mcp-remote bridge in claude_desktop_config.json:

{
  "mcpServers": {
    "clarkhuang": {
      "command": "npx",
      "args": ["mcp-remote", "https://gitmcp.io/clarkhuang/clarkhuang.github.io"]
    }
  }
}

Cursor

Add this to ~/.cursor/mcp.json (or the project .cursor/mcp.json):

{
  "mcpServers": {
    "clarkhuang": {
      "url": "https://gitmcp.io/clarkhuang/clarkhuang.github.io"
    }
  }
}
