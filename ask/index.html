    Connect your AI (MCP)
    
        
    First-party option: this site also ships its own small, read-only site MCP server (stdio, one Python file, no dependencies) with tools for lessons, transcripts, captions, media checks, search, and contributor-style issue drafts. Claude Code: claude mcp add clarkhuang-site -- uv run https://clarkhuang.github.io/mcp/clarkhuang_site_mcp.py. The GitMCP endpoint below is a remote, third-party alternative; its full-text fetch is current, but its search can lag behind the site.
    
        
    This project has a public, read-only GitMCP endpoint:
    
        
    https://gitmcp.io/clarkhuang/clarkhuang.github.io
    
        
    GitMCP is a free third-party service. It is not affiliated with this site. It only reads public documentation (it prefers llms.txt) and public code. It cannot open issues, merge pull requests, or change the book. To contribute, file a GitHub issue — see Contribute with your AI.
    
        
    The tools it exposes for this repository are fetch_clarkhuang_docs, search_clarkhuang_docs, search_clarkhuang_code, and fetch_generic_url_content.
    

        
    Claude Code
    
        
    claude mcp add --transport http clarkhuang https://gitmcp.io/clarkhuang/clarkhuang.github.io
    
        
    

        
    Claude Desktop
    
        
    If your Claude Desktop build supports a remote HTTP MCP server, add the URL above. Otherwise use the mcp-remote bridge in claude_desktop_config.json:
    
        
    {
  "mcpServers": {
    "clarkhuang": {
      "command": "npx",
      "args": ["mcp-remote", "https://gitmcp.io/clarkhuang/clarkhuang.github.io"]
    }
  }
}
    
        
    

        
    Cursor
    
        
    Add this to ~/.cursor/mcp.json (or the project .cursor/mcp.json):
    
        
    {
  "mcpServers": {
    "clarkhuang": {
      "url": "https://gitmcp.io/clarkhuang/clarkhuang.github.io"
    }
  }
}
