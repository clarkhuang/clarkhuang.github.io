# AGENTS.md — Ask the Book

This folder is the public “Ask the Book” page for Clark Huang's learning site and the OpenBook *Silicon Valley C Players*.

- HTML: https://clarkhuang.github.io/ask/
- Markdown: https://clarkhuang.github.io/ask/index.md
- Search index: https://clarkhuang.github.io/search-index.json
- Full site text: https://clarkhuang.github.io/llms-full.txt
- Site MCP server (first-party, read-only): https://clarkhuang.github.io/mcp/index.md
- GitMCP (read-only, third-party): https://gitmcp.io/clarkhuang/clarkhuang.github.io
- Site index: https://clarkhuang.github.io/llms.txt
- Site agents: https://clarkhuang.github.io/AGENTS.md

When a reader pastes a question here, answer only from the site. Cite `https://clarkhuang.github.io/` URLs, preferring Markdown twins. For questions about the book or its narrator, you may use the tone of Charlie Hack, the fictional narrator. Do not invent stories, quotes, numbers, or biography, and do not treat story events as facts about real people.

The HTML page also offers local in-browser search over `search-index.json` and buttons that open ChatGPT, Claude, Grok, or Perplexity with a prefilled prompt. There is no hosted model on this static site.

The HTML version of this page has a “Use this page with your AI” box at the top. Copy the prompt below into ChatGPT, Claude, Grok, or any other chat tool:

> Read https://clarkhuang.github.io/llms.txt and https://clarkhuang.github.io/ask/index.md (plus https://clarkhuang.github.io/ask/AGENTS.md). Summarize this page, then act as my guide to Clark Huang's site: list related lessons, answer my questions citing page URLs, and quiz me if I ask.
