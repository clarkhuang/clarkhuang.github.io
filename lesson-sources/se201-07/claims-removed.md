# SE201 Lesson 7: claims softened or removed, and why

All of these were changed between the first draft and the recorded script (round 1). Round 2 changed nothing. The "first draft" column quotes or summarises the wording recorded in the round-1 review (`se201-07-review-round1.md`); the first-draft script itself was overwritten by the revision.

| Scene | First draft | Recorded | Why |
|---|---|---|---|
| 07_improve | "Same result, whoever runs it." | "No guarantee: agents still vary. That's what the checks are for." | A written skill does not make an agent deterministic. The honest claim is that the page narrows the variation and the checks catch the rest. |
| 05_runbook | "An agent runs the skill every time, and follows the page closely." | "An agent reads the skill on every run, with no memory of the last. Where the page is silent, it guesses." | "Follows the page closely" promised obedience. What is true is that a fresh agent has only the page, and fills gaps by guessing. |
| 04c_checks | "This is the part most write-ups leave out." | Removed. | An unsourced claim about what other people write. |
| 03_reuse | "Each of those packages code." | "All three reuse software." | A service is running software, not packaged code. |
| 03_reuse, on screen | Label "ROUGHLY IN THE ORDER THEY BECAME COMMON" (already hedged) | Kept unchanged | Not a change: recorded here because the hedge is deliberate. The three overlap in time; the order is approximate. |
| 04a_when | "Several agent tools now have a format for this" | "Several agent tools now share a format for this: a folder, with an instruction file." | Says only what the public format is; no tool or vendor is named and no adoption figure is given. |
| 04d_traps | The card and narration had an OUTPUT section as well | Dropped; five parts | The example never used it, and the rule should name only what the lesson showed. |
| 06_test | "next to the system it changes" | "Keep it in the repository, versioned, and reviewed when it changes." | Removed an implied claim about where every team keeps such files. |
| 08_when | "The third time." | "A good rule of thumb: the third time... Sooner, if a mistake costs money." Label on screen: "A RULE OF THUMB". | It is a heuristic, not a law, and the lesson's own example (a price) is a case where waiting is too long. |
| 12_close | "...with nobody watching" | "some of it should start on its own" | "Nobody watching" contradicts lessons 5 and 6, where people decide and every run is watched. |

## Kept out from the start

- No statement that the narrator, or any company the narrator worked for, uses skills or has had any of these failures. The example is called made up aloud and on screen.
- No named tools, vendors or people.
- No numbers or statistics (for example, no claim about how much a skill reduces errors).
- "The third time" is not attributed to anyone by name.

## Left as recorded, flagged in round 2 as minor

- 05: "with no memory of the last" is true of a fresh session; some tools keep memory between sessions. "Often with no memory" would be safer. Not re-recorded.
- 04d: "so nobody repeats it" is a shade strong next to 07's "No guarantee". Not re-recorded.
