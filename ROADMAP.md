# Roadmap

*Silicon Valley C Players* and [clarkhuang.github.io](https://clarkhuang.github.io) are one software project. Versions are cut like software releases. See [book-source/VERSIONING.md](book-source/VERSIONING.md) for the branching and tagging model.

Contributions (issues and pull requests) are welcome now. Reaching out to people mentioned in the stories to invite their side still waits for v1.0 and Clark's go-ahead.

## v0.1 Teaser (current)

Milestone: [v0.1 Teaser](https://github.com/clarkhuang/clarkhuang.github.io/milestone/1)

- Production-ready public site: bio, AI Tips, Software Engineering 101, Software Engineering 201 (From Loops to Building Systems) lesson 1, with lessons 2–8 outlined
- AI-friendly layer (`llms.txt`, `AGENTS.md`, Markdown twins, “Use this page with your AI”)
- Book teaser and matching videobook preview, with the OpenBook framing and the fiction disclaimer (names changed)
- Issue tracker, labels, and the self-updating workflow (approve → agent PR into `next-revision` → Clark merges)

## v1.0 First full draft

Milestone: [v1.0 First full draft](https://github.com/clarkhuang/clarkhuang.github.io/milestone/2)

Target: 2027, the first complete edition of the book.

- Remaining interview sessions and chapter drafts
- Technical half folded in from AI Tips, Software Engineering 101 and 201, plus a chapter on how companies should use AI
- First full audiobook and videobook, tagged as `book-v1.0` and kept as a GitHub Release
- Media/publishing attorney pre-publication review of v1 (manuscript, scripts, contributor terms); consider media liability insurance
- After this ships, invite people from the stories to add their side (outreach waits for Clark's go)

## Later editions

- **v1.1, v1.2, …** — corrections, new stories, and refactors accumulated on `next-revision`, then cut only when Clark approves that revision. Each cut is tagged (`book-v1.1`, …) and keeps its own audiobook and videobook assets. Prior tags stay up.
- **v2** — a larger revision if the OpenBook has grown enough to warrant it.
- The site will link previous editions from the book page.
